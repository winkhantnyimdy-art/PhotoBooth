# PhotoBooth Premium Design Package

A + C + F = Retro Pop × Vintage Film × Cute Illustration.

- `reference_full.png`: approved concept board
- `screens/`: five cropped reference screenshots (include mockup frames)
- `assets/`: five visual art references, **not production-ready artwork**
- `design_tokens.json`: initial approximate colors, responsive targets
- `screen_specs.md`: product and QA blueprint
- `opencode_build_prompt.md`: ready-to-paste agent instructions

## Setup
Extract this folder into `C:\Users\jpas\Downloads\PhotoBooth\design\PhotoBooth_Premium_Design` (or adjust the prompt path). Then paste `opencode_build_prompt.md` into OpenCode. No manual design work is needed. OpenCode must generate original reusable production assets and verify screenshots.

This package does not include Flutter source code or independently verified emulator screenshots. Visual fidelity remains subject to implementation and verification.
